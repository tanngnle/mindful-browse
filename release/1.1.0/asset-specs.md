# Graphic Asset Specifications

> These are the images you need to create and upload to the Store Listing tab.

## Required Assets

### Store Icon
- **Size:** 128x128 pixels
- **Format:** PNG (no alpha) or JPEG
- **Notes:** You already have `icons/icon128.png` — this can be reused directly
- **Upload to:** Store listing > Graphic assets > Store icon

### Screenshots (at least 1, max 5)
- **Size:** 1280x800 or 640x400 pixels
- **Format:** JPEG or 24-bit PNG (no alpha)
- **Required:** At least 1

**Suggested screenshots to capture:**

| # | What to show | How to capture |
|---|---|---|
| 1 | The blocked page with Pomodoro timer running | Load `blocked/blocked.html` directly in a tab, start a timer, screenshot at 1280x800 |
| 2 | The popup with site management | Open the extension popup, add a few example sites, screenshot |
| 3 | YouTube strip mode in action | Visit YouTube with strip mode enabled, show the cleaned layout |
| 4 | The flip-clock timer close-up | Focus on the timer display during a work session |
| 5 | Scheduling rules or friction rules in the popup | Show the settings/configuration UI |

## Optional Assets

### Small Promo Tile
- **Size:** 440x280 pixels
- **Format:** JPEG or 24-bit PNG (no alpha)
- **Notes:** Used in smaller store UI placements

### Marquee Promo Tile
- **Size:** 1400x560 pixels
- **Format:** JPEG or 24-bit PNG (no alpha)
- **Notes:** Used in featured/hero placements

### Global Promo Video (optional)
- **Format:** YouTube URL
- **Notes:** A short demo video can significantly boost installs

## Quick Reference
