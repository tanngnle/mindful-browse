## Description (REQUIRED — currently empty)
```
MindfulBrowse helps you reclaim your focus by intercepting distracting websites and replacing them with a calming Pomodoro timer.

HOW IT WORKS
━━━━━━━━━━━━
• Add any distracting domain (e.g. youtube.com, facebook.com, reddit.com) to your block list.
• When you navigate to a blocked site, MindfulBrowse redirects you to a full-screen Pomodoro timer instead.
• Work for 25 minutes, then the timer unlocks the site for a 5-minute break.

KEY FEATURES
━━━━━━━━━━━━
• Beautiful flip-clock timer with work/break cycles
• Configurable work duration and break length
• YouTube & Facebook strip mode — removes recommended feeds and sidebars while keeping the core content visible
• Friction rules — adds intentional delays to break impulse browsing habits
• Scheduling rules — set automatic focus sessions by time of day or day of week
• 100% private — no accounts, no tracking, no network requests. All data stays on your device.

WHY MINDFULBROWSE?
━━━━━━━━━━━━━━━━━━
Unlike other site blockers that simply deny access, MindfulBrowse replaces distraction with intention. The Pomodoro technique is proven to improve concentration and reduce burnout. By turning every impulse to procrastinate into a focused work session, MindfulBrowse helps you build healthier browsing habits over time.

PRIVACY FIRST
━━━━━━━━━━━━━
• Zero network requests — the extension works entirely offline
• Self-hosted fonts — no third-party CDN calls
• No analytics, no tracking, no data collection
• Your settings are stored locally via chrome.storage
```
