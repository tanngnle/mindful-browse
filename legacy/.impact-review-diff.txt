    Remove AI implementation (Bao on-device chat)
    
    User decision to drop the AI implementation entirely. The only AI in the project was the Bao on-device panda chat (Chrome Prompt API / Gemini Nano), so this removes it root and branch:
    
    - Delete lib/panda-agent.js (Prompt API agent), blocked/blocked-chat.js and blocked/blocked-chat.css (chat overlay), and tests/lib/panda-agent.test.js
    
    - Remove chat overlay markup and launcher from blocked/blocked.html, and the chat-coupled pieces from blocked/blocked.js (Space-overlay guard, window.__focusguardTimer API exposed for the chat's timer strip, panda-chat-active particle throttle)
    
    - Revert manifest additions made for the AI: minimum_chrome_version 138 and the blocked-chat/panda-agent web_accessible_resources entries
    
    - Update blocked-page tests: drop chat-overlay suites, assert via DOM/storage instead of the removed __focusguardTimer hook, and move keyboard-shortcut tests to their own file (document-level listeners accumulate across mounts within one jsdom file)
    
    - Scrub Bao/chat references from README.md, CONTEXT.md, docs/QA-TEST-PLAN.md, docs/research-product-roadmap.md and stale CSS/HTML comments
    
    Kept intact: Pomodoro blocked page, breathing page, DOM stripping, friction engine, popup, and the heuristic-only intent classifier (no AI model involved). The extension still makes zero network requests.
    
    Verification: npx vitest run -> 12 files / 203 tests passed (baseline was 222; removed suites covered only the AI feature). npx eslint . -> 0 errors, 10 pre-existing warnings unchanged from master.
